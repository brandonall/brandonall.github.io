# Daily Catholic Readings

This site displays the daily Catholic Mass readings with audio narration and reflection questions.

### Features
- Daily Mass readings (full text)
- Audio narration (ElevenLabs, Brian voice)
- 6 personal reflection questions (generated with Grok)

### How to Use
Visit https://brandonall.github.io  
Read, listen, or reflect on the questions. Bookmark for daily use.
